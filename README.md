## Список реализованных тестов

| Тест | Описание |
|------|----------|
| `test_add_new_book_add_one_book_success` | Проверка успешного добавления одной книги в пустой словарь `books_genre` |
| `test_add_new_book_add_two_book_success` | Проверка корректного добавления нескольких разных книг в словарь |
| `test_add_new_book_valid_name_success` | Параметризованный тест проверки граничных значений длины названия книги (1 символ и 40 символов) |
| `test_add_new_book_invalid_name_length_41` | Параметризованный тест проверки негативных сценариев: название не должно быть пустым или длиннее 40 символов |
| `test_set_book_genre_existing_genre` | Проверка успешной установки существующего жанра из списка `genre` для добавленной книги |
| `test_get_books_with_specific_genre_two_books_succsess` | Проверка фильтрации книг по конкретному жанру (возвращает список названий) |
| `test_get_books_for_children` | Проверка получения списка книг для детей (исключаются жанры с возрастным рейтингом: `Ужасы` и `Детективы`) |
| `test_add_book_in_favorites_one_book_list_of_book` | Проверка успешного добавления существующей книги в список избранного |
| `test_add_book_in_favorites_one_book_not_in_list_of_book` | Проверка того, что книгу нельзя добавить в избранное, если её нет в основном словаре `books_genre` |
| `test_delete_book_from_favorites` | Проверка успешного удаления книги из списка избранного |
| `test_get_book_genre_non_existent_book` | Проверка того, что при поиске жанра несуществующей книги возвращается `None` |
